# 기억 포커
Node.js 18 이상에서 npm install 후 npm start. 브라우저 http://localhost:3000 접속. 친구와 인터넷 대전하려면 Render Web Service에 이 폴더를 Git 저장소로 올리고 Build Command npm install, Start Command npm start 설정. 단일 서버 인스턴스 사용. 공개 URL을 공유하면 됩니다. 실제 배포는 포함되지 않습니다.

시간 초과 시 미선택 카드는 무작위 배정. 공동 순위 동일 점수. AI는 16장 중 9장만 기억한다고 가정하여 최적 조합 선택. 서버 메모리에 방 저장: 서버 재시작 시 초기화. 공개 단계에서 브라우저가 받은 카드를 개발자 도구로 기록하는 행위까지 막을 수는 없습니다. 재접속은 동일 브라우저 저장 토큰 기반입니다.
